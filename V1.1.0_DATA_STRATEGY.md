# v1.1.0 Data Strategy: Real Rogers Park Events

## Overview
Rogers Park has a vibrant, unique local culture that deserves authentic representation. This document outlines our strategy for collecting real, community-focused event data that captures the neighborhood's character beyond what official APIs provide.

## Why This Matters
Rogers Park is often "lost in Chicago" - a tight-knit neighborhood with deep community roots. Events like "Paint the Wall," local festivals, and grassroots cultural happenings define the neighborhood. Our app should reflect this authentic culture.

## Data Sources

### Official/Scheduled Events
- **Chicago Parks District** - Lakefront events, summer programs, park activities
- **City of Chicago (Ward 49)** - Cultural events, municipal programming
- **Rogers Park Library** - Community programs, public events
- **Chicago.gov Events** - City-wide events filtered for Rogers Park area

### Local Community Organizations
- **Rogers Park Community Organization** - Neighborhood programming
- **Rogers Park Merchant Association** - Local business events

- **Faith-based organizations** - Community gatherings

### Community Platforms

## Data Collection Process

### Step 1: Initial Research (This Week)
- [ ] Browse Chicago.gov parks/events for Rogers Park
- [ ] Search Rogers Park organizations websites
- [ ] Check local Facebook groups & Nextdoor
- [ ] Research local bars, restaurants, venues
- [ ] Look for any Rogers Park event listings/calendars

### Step 2: Compile & Verify
- [ ] Create master list of 15-20 events
- [ ] Verify dates, times, locations are accurate
- [ ] Confirm events are real and upcoming
- [ ] Identify organizers/venues
- [ ] Note data sources

### Step 3: Normalize Data
- [ ] Ensure all events have required fields
- [ ] Categorize events properly
- [ ] Verify wheelchair accessibility info
- [ ] Add descriptions from official sources

### Step 4: Update db.json
- [ ] Replace mock data with real events
- [ ] Test data structure integrity
- [ ] Verify API returns correct data

## Data Quality Standards

For v1.1.0, all events must meet these standards:

**Accuracy:**
- Real events in Rogers Park area
- Correct dates and times
- Verified venue information
- Accurate contact/organizer info

**Completeness:**
- All required fields populated
- Descriptive but concise descriptions
- Proper categorization
- Wheelchair accessibility verified or noted

**Community Value:**
- Reflects Rogers Park culture and character
- Mix of official and grassroots events
- Represents diverse community interests
- Authentic neighborhood perspective

## Sources Documentation

For each event in db.json, we should note:
- Where the event info came from
- Date we verified the information
- Any special notes about the event

Example:
```json
{
  "id": "event-001",
  "title": "Rogers Park Farmers Market",
  "source": "Chicago Parks District official calendar",
  "verified_date": "2025-04-24",
  "notes": "Recurring Saturday event, verified current"
}
```
